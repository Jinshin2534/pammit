# ラベル定義

画像のラベルには2つの層がある。この2つは混ぜない。

| 層 | 内容 | 決める人 |
|---|---|---|
| 検出クラス | 画像から見つける物体（実・葉など） | AI 担当（アノテーションの対象） |
| 判定 | システムが返す答え（摘む / 残す） | 検出結果から計算する |

「摘むべき実」を検出クラスにしない。同じ見た目の実でも、周りの混み具合によって正解が変わるため、モデルが学習できない。

## 検出クラス

| id | クラス | 内容 | 優先度 |
|---|---|---|---|
| 0 | `fruit` | すだちの実 | 必須 |
| 1 | `leaf` | 葉 | 高 |
| 2 | `branch` | 枝 | 中 |
| 3 | `calyx` | ヘタ | 低 |
| 4 | `scissors` | ハサミ（刃先を含める） | 低 |
| 5 | `hand` | 手 | 低 |

撮影に手袋のマーカーは使わない。実の大きさは画像の中での相対的な大きさで扱い、絶対的な大きさ（mm）は持たない。

## 観察ラベル

実ごとに、画像から見える状態を記録する。

| 項目 | 値 | 意味 |
|---|---|---|
| `light_state` | `sunlit` / `shadowed` / `unclear` | 実の表面の明暗 |
| `leaf_cover_state` | `covered` / `not_covered` / `unclear` | 葉が実にかぶって見えるか |

`unclear` は「判断できない」というラベルで、未入力とは区別する。
画像の明暗やかぶりだけから、日照時間や摘果すべきかどうかを決めない。

## 判定

```text
verdict: "take" | "keep" | "unknown"
```

| 値 | 摘果・摘葉 | 収穫 |
|---|---|---|
| `take` | 摘む | 収穫する |
| `keep` | 残す | まだ収穫しない |
| `unknown` | 判断できない | 判断できない |

摘果と収穫で同じ値を使う。どちらも「今それを取るかどうか」の判断で、作業の種類はセッションが持つ。

理由の候補は次の通り。栽培上の基準や閾値は、熟練者の確認と評価を経て決める。

| コード | 意味 | 音声の例 |
|---|---|---|
| `too_small` | 周りの実より小さい | 「小さいので摘んでください」 |
| `too_dense` | 周りが混んでいる | 「混んでいるので摘んでください」 |
| `shaded` | 日が当たっていない | 「日が当たらないので摘んでください」 |
| `damaged` | 傷がある | 「傷があります」 |
| `low_confidence` | 自信がない | 「判断できません」 |

## アノテーションのルール

| 項目 | ルール |
|---|---|
| 隠れている実 | 半分以上見えていれば囲う |
| 画面の端で切れている実 | 囲わない |
| 遠くのぼやけた実 | 囲わない。手が届く距離のものだけ |
| 葉 | 1枚ずつ囲う |
| 房になった実 | 1個ずつ囲う。房をまとめて囲わない |

房をまとめて囲うと、個数も混み具合も計算できなくなる。

## 熟練者による正解ラベル

既存の動画に後から摘果・摘葉の判断を付けるときは、撮影時の作業結果と混ぜない。
実ごとに、作業の種類、判定、理由、判断した人、判断した日、元の動画と時刻を記録する。
その作業の基準を当てはめられない場面（収穫期の映像など）は `not_applicable` とし、`unknown` や `keep` に混ぜない。
