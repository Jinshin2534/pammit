# ハードウェア

帽子と農地センサーの2つがある。帽子はスマートフォンとつながり、農地センサーはサーバーへ直接データを送る。

## 帽子

撮影と音声の再生だけを担当する。推論と判定はスマートフォンで行う。

| 部品 | 製品 |
|---|---|
| 本体 | Raspberry Pi Zero 2 WH |
| カメラ | Raspberry Pi カメラモジュール V3（広角） |
| 記録媒体 | microSD 32GB（KIOXIA EXCERIA） |
| 電源 | モバイルバッテリー 5000mAh（エレコム DE-C45-5000PU） |
| 音声 | USB オーディオ変換アダプター（UGREEN）、ピンマイク、スピーカー（バッファロー BSSP105UBK） |
| その他 | USB ハブ（micro USB、OTG）、アクリルケース |

### 帽子の API

スマートフォンのテザリングで同じネットワークにつなぎ、HTTP で操作する。

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/status` | 接続の確認 |
| GET | `/capture` | JPEG を1枚返す |
| POST | `/command` | 定型の音声を再生する。`{"command": "TAKE"}`。値は `TAKE` / `KEEP` / `UNKNOWN` |

ポートは 5000。テザリングでは帽子の IP アドレスが変わることがあるため、アプリで接続先を設定できるようにする。

### 決まっていないこと

- 帽子で合図の言葉（「パミット、これ？」など）を聞き取ったとき、スマートフォンへ知らせる方法
- 位置を含めて案内する場合の `/command` の形
- 音量・話す速さを帽子側で変える方法
- 連続で使える時間、重さ、発熱、マイクとスピーカーの音の回り込み

## 農地センサー

農地に置いて、10〜30分ごとに測った値をサーバーへ送る。

| 部品 | 製品 |
|---|---|
| マイコン | ESP32（Freenove ESP32 Dev Board） |
| 土壌水分 | 容量式の土壌水分センサー（Hailege） |
| 気温・湿度・気圧 | BME280（GY-BME280-3.3V） |

土壌水分は ADC の生値のまま送り、%への換算はサーバーで行う。換算には、その農地の土で測った乾燥時と飽和時の生値を使う。
電池残量は今のところ測れない。

送信先・認証・データの形は [aws.md](aws.md) にある。

本番の構成では LoRaWAN（The Things Network 経由）で送ることを想定している。サーバー側の受け口は実装済みだが、LoRa モジュールとゲートウェイは用意していない。
