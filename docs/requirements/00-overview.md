# 概要・対象者・KPI

## プロジェクト

**パミット** — ベテランすだち農家の判断を、誰でも使える形にするシステム

日除け帽子デバイス（カメラ・マイコン・スピーカー）とスマートフォンアプリで構成する。

- 部門: 課題部門
- 対象者: すだち農家
- 本選: 2026年10月

## 背景

徳島県はすだちの全国シェア98%を占め、なかでも神山町は県内最大の産地（県内シェア32%、1,317t）。
しかし栽培面積・収穫量はいずれも減少傾向にあり、担い手不足により耕作放棄地が増えている。

- 新規就農者の57.7%が「営農技術の習得」に苦労したと回答（全国新規就農相談センター）
- 農業は知識と経験に基づく高い熟練性を必要とし、新規参入が容易ではない（農林水産省）

## 対象範囲

**ハウス栽培と露地栽培の両方を対象とする。**

両者は環境条件も作業時期も大きく異なるため、`plots.cultivation_type` で分岐させる。

| | ハウス | 露地 |
|---|---|---|
| 収穫期 | 6〜8月 | 8〜9月 |
| 摘果 | — | 5月〜9月中旬（神山町） |
| 土壌水分を決めるもの | **灌水** | 降水＋灌水 |
| 気温・湿度 | 外気と大きく異なる（夏は40〜50℃） | 外気とほぼ同じ |

| 課題 | 出所 |
|---|---|
| 後継者育成でほぼ専属状態になり、自身の作業効率と収益が落ちる | 農家インタビュー ※下記の注意を参照 |

| 作業ログが手書き中心で、栽培暦への転記が負担 | 農家インタビュー |

### アルバイト・新規就農者

| 課題 | 出所 |
|---|---|
| 摘果・摘葉・収穫の判断ができず、商品に傷をつける | 農家インタビュー |
| 傷がつくと冷蔵可能期間が短くなり、県外発送ができなくなる | 永野裕介さん（NPO法人里山みらい） |

### 根本課題

> **ベテランの判断基準が本人の中にしかなく、共有も記録もされていない。**

## 現地調査で判明したこと

2026年9月、収穫アルバイトとして2日間現場に入った。**前提が3つ覆っている。**
詳細は [research/README.md](../research/README.md)。

| 覆った前提 | 観測 |
|---|---|
| つきっきりで指導している | **指導は行われていない。** ハサミと規格板を渡され「はいお願いします」だった |
| 収穫の判断は難しい | **2日で慣れる。** 2日目には規格板なしで判断でき、収穫量が2倍になった |
| 課題は判断だけ | **「丁寧に扱う」ができていない。** すだちをポロポロ落とし、傷をつけている |

### 課題設定の修正

| | 予選資料 | 現地調査後 |
|---|---|---|
| 誰の問題か | 教える農家の負担 | **教わらない初心者の迷い** |
| 解決の方向 | 指導を代替する | **不在の指導を埋める** |

**教える人がいないのだから、代わるものが要る。** こちらのほうが切実な課題である。

※ 井出さん・永野さんは「教える負担が大きい」と証言している。農家による違いか、
繁忙期は教える余裕がないという時期差か、未確認。

### 価値の重心

**摘果・摘葉を主軸とする。**

| | 2日で慣れるか | 扱い |
|---|---|---|
| 収穫のサイズ判断 | **慣れる** | **廃止**（絶対サイズを測る手段がない） |
| **摘果・摘葉** | 未検証。「特に教育工程が多い」（井出さん） | **主軸** |
| 見逃し | 残る | 扱わない（探索は精度要求が高い） |
| 丁寧に扱うこと | 残る | 保留 |
| 剪定 | **慣れない**（2年目の研修生が困っている） | 今後の展望（時期が合わない） |

## 提供価値

1. **現場での判断支援** — **摘果・摘葉**の判断を、その場で音声で伝える
2. **記録のデータ化** — 摘果・摘葉・収穫は帽子のセッションから自動記録し、その他は3タップで記録する
3. **不在の指導を埋める** — 誰も教えてくれない状況で、初心者が迷わず作業できる状態をつくる

## KPI

| KPI | 現状 | 目標 | 測定方法 |
|---|---|---|---|
| 作業の質 | 70%（1週間指導後） | 95%（初日から） | **AI判定とベテラン判定の一致率** |
| 秀品率 | — | 向上 | 収穫物のうち傷のないものの割合 |
| ベテランの指導時間 | ほぼ専属 | 削減 | 質問回数・同行時間 |
| 記録の負担 | 手書き転記 | 帽子作業は自動・その他3タップ | 記録所要時間 |

### 測定方法（確定）

**「70%」「95%」は現時点で目標値であり、実測値ではない。** 本選までに実測値を出す。

根拠となる数字は**評価用データセットに対するAI一致率だけ**である。
判定フィードバック機能（旧F-08）を実装しないため、運用中の修正データは存在しない。

- 評価の定義は「**ベテラン農家の判定を正解とし、AI判定との一致率で測る**」
- **測定対象は摘果・摘葉の判定とする。** 収穫のサイズ判断は2日で慣れることが判明したため、
  そこで高い数値を出しても製品価値の証明にならない
- 学習用と評価用のデータを分ける。学習に使ったデータで測っても意味がない
- 評価用データセットの作成方法はAI担当に委ねる
- **サンプル数を必ず併記する。** 「95%」より「サンプル420件で92.4%」のほうが信頼される

目標値を下回っても、実測値を示すほうが強い。

## スコープ外

- 農薬使用記録の法定要件対応（PHI警告・使用回数チェック）— 本番では必須になるが、デモでは対象外
- マルチテナント・Row Level Security
- 帽子デバイスの量産・耐久設計
- レーザー照射（安全基準の検討により廃止）
- PHI警告・農薬使用回数チェック・灌水タイミング提案・熱中症警告・判定フィードバック
  （裏取りができていないため実装しない）
