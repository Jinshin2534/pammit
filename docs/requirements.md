# 要件

画面の構成は操作マニュアル（Figma）に合わせる。

## 利用者

| ロール | ログイン画面の表示 | できること |
|---|---|---|
| `owner` | 師匠農家さん | すべての画面と管理者画面 |
| `worker` | 後継者さん / アルバイト | 管理者画面以外 |

## 画面と機能

### ログイン

- 役割を選び、4桁の PIN を入力する
- 端末は前回ログインした人を覚えておき、PIN 画面に名前を出す。初めての端末では名前の一覧から選ぶ
- PIN は管理者が作業者を登録したときにサーバーが発行し、登録完了時に一度だけ表示する
- PIN を5回間違えると15分ロックする。ログインの有効期間は30日

### ホーム

- 今日のひとこと（短い文と、詳しく見たときの説明文）
- 今日の予定（時間・作業・園地・担当）
- 「作業を始める」「ベテランAI相談」「予定管理」への入口

今日のひとことは、予定・センサーの値・天気予報をもとに LLM が毎朝5時に生成する。OpenAI のキーがないときや失敗したときは、同じ材料から決まった形の文を作る。

### 作業を始める

1. 今日の予定から選ぶか、新しく始める
2. 園地を選ぶ
3. 作業を選ぶ
4. 帽子に接続する（カメラ・マイク・スピーカーの確認、音声のテスト）
5. 内容を確認して開始する

作業の種類は次の8つ。

| 作業 | 帽子での判定 |
|---|---|
| 剪定 | なし |
| 灌水 | なし |
| 肥料 | なし |
| 摘果・摘葉 | あり |
| 収穫 | あり |
| 防除 | なし |
| 草刈り | なし |
| その他 | なし |

すべての作業を「作業セッション」として記録する。作業ログはセッションの終了時に自動で作る。

### 作業中・終了

- 経過時間を表示する。帽子で判定する作業では、切る / 残す / 判断不可の件数も表示する
- 作業中に AI 相談ができ、その会話は作業セッションに紐づけて残す
- 作業終了は長押しで行い、確認画面を出す
- 終了後に「今日の気づき」を音声で残せる。音声ファイルをサーバーに送り、サーバーで文字に起こす

### 判定

作業者が帽子に向かって合図すると、スマートフォンが帽子から画像を1枚取得し、果実を検出して判定する。
結果は帽子のスピーカーから定型の音声で伝える。

| 判定 | 意味 |
|---|---|
| `take` | 摘む / 切る |
| `keep` | 残す |
| `unknown` | 判断できない |

自信がないときは `unknown` を返す。初心者向けの道具が自信を持って間違えることを最も避ける。
判定結果はその場でサーバーに送る。送る項目は [ai.md](ai.md) の検討結果に合わせて決める。

### 予定

- 月のカレンダーに、作業の種類ごとの色で予定を表示する
- 日を選んで予定を入力する（時間・園地・作業・担当・備考）。作業と担当は複数選べる
- 予定は人が入力する。1日ずつ登録し、くり返しの登録はしない

### 農園

- 土壌水分の現在値、前日との差、明日の予測を表示する
- 灌水についての助言を表示し、「確認を明日の予定に追加」で予定を1件作れる
- データ推移の画面で、土壌水分・気温・湿度・気圧のグラフを表示する
- 明日の最高気温と雨量を表示する

土壌水分（%）は、センサーの生値から園地ごとの2点校正（乾燥時・飽和時）で換算する。
明日の予測は、直近の変化を直線で延ばして求める。
灌水の助言はルールで出す。上から順に判定し、最初に当てはまったものを表示する。

| 条件 | 表示 |
|---|---|
| 明日の雨が10mm以上で、今の値が目安以上 | 明日は雨の予報です。今すぐの灌水は必要なさそうです |
| 今の値が目安（既定28%）未満 | 土が乾き気味です。今日中に土の状態を確認しましょう |
| 明日の予測が目安未満 | 明日には目安を下回りそうです。明日午前に土の状態を確認しましょう |
| 6〜9月で、24時間で減っていて、明日の最高気温が33℃以上 | 晴天が1週間続く場合は灌水を検討しましょう |
| どれにも当てはまらない | 今すぐの灌水は必要なさそうです |

言い方は「確認を促す」形に限り、灌水量は断定しない。目安・雨量・気温の値は園地ごとに変えられる。
すだち専用の数値基準は公的資料に見当たらないため、これらの値は県の指針（晴天が1週間続いたら灌水）をもとにした仮の値である。
明日すでに灌水の予定がある園地では「確認を明日の予定に追加」を出さない。
天気予報は Open-Meteo の気象庁モデルから1日1回取り込む（気象庁の予報 JSON には雨量がないため）。園地に緯度経度がなければ神山町の位置を使う。

### ベテランAI相談

- テキストで相談する。よく聞かれる話題をサジェストとして表示する
- 過去の会話を一覧で見られる
- 回答には、現地調査とインタビューの内容、作業者が残した「今日の気づき」を検索して使う

### 設定

- 帽子の接続状態の確認
- 音量、話す速さ（端末に保存）
- プロフィール（名前・アイコン）
- ログアウト

### 管理者画面（owner のみ）

- 作業者の登録（名前・性別・作業者の種別・週の最大稼働時間）
- 農園の登録（名前・所在地）
- 農園日誌: 日ごとの気温・天気・作業人数・作業内容を自動で作り、備考だけ手で書く。期間を指定して PDF を出力する（PDF はサーバーで作る）

## 非機能要件

| 項目 | 要件 |
|---|---|
| 応答時間 | 合図から最初の音声まで1秒以内 |
| 通信 | スマートフォンと帽子はテザリングの Wi-Fi で接続する。サーバーとの通信はインターネット接続を前提にする |
| 二重登録 | 書き込みは端末が作る `client_event_id` で重複を判定し、同じ要求が2回届いても1件にする |
| データの分離 | 農園（経営体）ごとにデータを分け、ログイン中の人の農園のデータだけを返す |
| 端末の負荷 | 判定は合図があったときだけ行い、常時の推論はしない |

## 決まっていないこと

- 判定結果としてサーバーに送る項目の形
- 帽子で「なんで？」と聞いたときの説明を、どの経路で返すか
- 音量・話す速さを帽子側で変えられるか
