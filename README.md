# パミット（pammit）

ベテランすだち農家の判断を、誰でも使える形にする技能継承システム。
帽子型デバイスとスマートフォンを使い、摘果・摘葉の判断を音声で支援します。

## AIの最新状況

[AIの最新説明・評価結果・開発方針](docs/ai/README.md)を参照してください（2026-10-02更新）。
果実検出はPixel 7aで動作確認済みです。実ごとの明暗・葉のかぶりは試作評価中で、作業判断と位置付き音声の統合は未完成です。葉の個体検出は現在の必須範囲から外しています。

## ハード開発担当へ

使用するハードは購入済み・注文済みですが、構成や接続方法などの内容はまだ詰め切れていません。
[購入・注文済みハード一覧](docs/hardware-inventory.md) を前提に、具体設計・接続確認・試作をハード開発担当に引き継ぎます。
既存資料の構成・通信方式は設計案であり、購入部品で動作検証済みの完成仕様ではありません。
初めてハードを作る人は、まず [何を・なぜ・どの順番で決めるか](docs/hardware-decisions.md) を読んでください。
担当範囲は [ハード開発の引き継ぎ](docs/hardware-handoff.md) にまとめています。
既存の要件、アプリとの接続境界、着手順、未確定事項をまとめています。

## 現在の状態

要件資料とFastAPIのAPI契約スタブを共有しています。
**センサー受信（F-10）だけは実装済み**で、AWS（EC2 + RDS + S3）上で受信・保存できます。構成と操作は [AWS とセンサー受信](docs/aws.md) を参照してください。
それ以外のエンドポイントはスタブ応答であり、実際の認証・保存・外部連携の完成を示すものではありません。
Androidの果実検出検証アプリはローカルで実装・実機検証しています。本体アプリや帽子との全経路が完成したことを示すものではなく、ソース・モデルの共有範囲と接続状況は上のAI説明を参照してください。

製品要件は `docs/`、APIの型と現在の契約はFastAPIの `/docs` を参照してください。
仕様変更時は関係する資料も同じ変更で更新します。
