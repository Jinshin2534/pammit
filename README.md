# パミット（pammit）

ベテランすだち農家の判断を、誰でも使える形にする技能継承システム。
帽子型デバイスとスマートフォンを使い、摘果・摘葉の判断を音声で支援します。

## ハード開発担当へ

使用するハードは購入済み・注文済みですが、構成や接続方法などの内容はまだ詰め切れていません。
[購入・注文済みハード一覧](docs/hardware-inventory.md) を前提に、具体設計・接続確認・試作をハード開発担当に引き継ぎます。
既存資料の構成・通信方式は設計案であり、購入部品で動作検証済みの完成仕様ではありません。
まず [ハード開発の引き継ぎ](docs/hardware-handoff.md) を確認してください。
既存の要件、アプリとの接続境界、着手順、未確定事項をまとめています。

| 読む順 | 資料 | 内容 |
|---|---|---|
| 1 | [ハード開発の引き継ぎ](docs/hardware-handoff.md) | 担当範囲・接続仕様・試作の確認項目 |
| 2 | [ドキュメント一覧](docs/README.md) | 全体構成・保留案・未決事項 |
| 3 | [機能要件](docs/requirements/01-requirements.md) | 帽子の映像・音声、遅延、オフライン要件 |
| 4 | [API仕様](docs/requirements/04-api.md) | センサー受信・アプリ連携 |
| 5 | [バックエンド](backend/README.md) | ローカル起動とSwagger UI |

## 現在の状態

要件資料とFastAPIのAPI契約スタブを共有しています。
バックエンドはスタブ応答であり、実際の認証・保存・外部連携の完成を示すものではありません。
このリポジトリには帽子のファームウェア、回路図、スマートフォンアプリの実装はまだありません。

製品要件は `docs/`、APIの型と現在の契約はFastAPIの `/docs` を参照してください。
仕様変更時は関係する資料も同じ変更で更新します。
